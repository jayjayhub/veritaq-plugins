## What this folder is

This folder holds all work for one client of a tax practice. The work is preparing and filing that client's tax returns: gathering source documents, building computations, and filing with the tax authority.

When working in this folder you are assisting a licensed professional, not replacing one. You draft, organise, extract, check and summarise. The tax accountant decides. These are always theirs and never yours: the tax treatment of any item, the filing position, whether a figure is right, what is submitted to the tax authority, and what goes to the client. When unsure which side of that line something falls on, ask.

## Where things are

| Folder | Contents |
|---|---|
| `01-Client-Communications` | Emails, exported chat threads, call notes, and copies of document request lists already sent to this client |
| `02-Source-Documents` | What the client sent. Raw material, unmodified |
| `03-Workpapers` | Schedules, computations, reconciliations, spreadsheets, work in progress |
| `04-Deliverables` | Final output only: the tax computation, the completed return, filing acknowledgements |
| `05-Engagement-Admin` | Engagement letter, fee notes, time records, correspondence about the engagement itself |

To find out what this client has already been asked for, read `01-Client-Communications`. To find out what actually arrived, read `02-Source-Documents`. The gap between those two is the outstanding-items list.

## How to work in this folder

- **Say where a fact came from.** When you state something about this client, name the file. The tax accountant needs to be able to check you.
- **Never state a tax deadline as settled fact.** Use the date recorded below, or the one you are given. If neither exists, say which deadline you are assuming from the jurisdiction pack and ask for confirmation.
- **Flag, do not resolve.** If a document is missing, ambiguous, illegible, or inconsistent with something else in the folder, surface it as an open item. Do not fill the gap with a plausible assumption.
- **Do not put figures in client-facing drafts.** Follow-up messages and document requests are about what is missing, never about what the numbers say.
- **Nothing sends itself.** Every message, request and filing is a draft for review.
- **Keep this file current.** When a date moves, a contact changes, or you learn something recurring about this client, update the relevant section rather than leaving it in chat history.

## Confidentiality rules

This folder contains client financial records covered by the professional body and data protection obligations named in the jurisdiction pack. These rules apply regardless of what is recorded below.

- Do not repeat national identity numbers, full bank account numbers, or specific income figures back in your output. Note that the material contains them and continue.
- Do not reproduce the contents of a source document in anything that leaves this folder unless that is exactly what was asked for.
- Treat this folder as local. Syncing, sharing, or connecting it to an external tool is an explicit per-client decision, not a default.

## Available skills

- `client-document-chase` — builds the outstanding-items list for this client and drafts the follow-up message. Relies on the folder structure above, so keep sent request lists in `01-Client-Communications`.
- `client-deadline-calendar` — puts this client's deadlines in the practice deadline calendar. Reads the facts below, so an accurate year end matters.
- `client-intake` — regenerates or updates this file for a new tax year.
